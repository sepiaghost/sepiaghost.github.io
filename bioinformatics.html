biophysics

Hodgkin-Huxley Neuron Model

A numerical implementation of the Hodgkin & Huxley (1952) model of the action potential in the squid giant axon — four coupled nonlinear ODEs, solved with an adaptive solver (deSolve::ode(), lsoda) rather than the fixed-step Euler's method used in the original hand-computed version.

A personal recreation: this started as an undergraduate biophysics assignment built by hand in Excel, assigned by the professor who is now writing one of my Ph.D. recommendation letters. Rebuilding it in R extends the original with an F-I curve sweep to locate rheobase and a double-pulse protocol to measure the absolute refractory period.

variant analysis

Variant Analysis Pipeline: Germline QC and Tumor-Normal Somatic Filtering

A dependency-free Python pipeline that reads VCF files and runs two stages: germline QC and summary (Ti/Tv, het/hom ratio, gene annotation), then tumor-normal filtering that labels every candidate site as somatic or rejects it with a named reason. It writes a command-line summary and a self-contained HTML report with inline charts: substitution spectrum, tumor VAF histogram, and an implied purity.

0.95 / 0.88clonal / subclonal recall, baseline synthetic tumor
0.33subclonal recall at purity 0.3
0.59precision when artifacts reach 4-6 alt reads
20tests

Scored on synthetic tumor-normal data with known truth, across nine scenarios and 20 seeds each. The README states where it breaks: no strand-bias or base-quality evidence, tumor contamination of the normal costs recall, and nothing here has been validated on a real caller's output.
